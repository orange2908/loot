Curated CTF tools for **forensics** (solve).

> Tools used for solving Forensics challenges; Registry Viewers

| Tool | What it does | Link |
|---|---|---|
| Aircrack-Ng | Crack 802.11 WEP and WPA-PSK keys. | <http://www.aircrack-ng.org/> |
| Audacity | Analyze sound files (mp3, m4a, whatever). | <http://sourceforge.net/projects/audacity/> |
| Bkhive and Samdump2 | Dump SYSTEM and SAM files. | <http://sourceforge.net/projects/ophcrack/files/samdump2/> |
| CFF Explorer | PE Editor. | <http://www.ntcore.com/exsuite.php> |
| Creddump | Dump windows credentials. | <https://github.com/moyix/creddump> |
| DVCS Ripper | Rips web accessible (distributed) version control systems. | <https://github.com/kost/dvcs-ripper> |
| Exif Tool | Read, write and edit file metadata. | <http://www.sno.phy.queensu.ca/~phil/exiftool/> |
| Extundelete | Used for recovering lost data from mountable images. | <http://extundelete.sourceforge.net/> |
| Fibratus | Tool for exploration and tracing of the Windows kernel. | <https://github.com/rabbitstack/fibratus> |
| Foremost | Extract particular kind of files using headers. | <http://foremost.sourceforge.net/> |
| Fsck.ext4 | Used to fix corrupt filesystems. | <http://linux.die.net/man/8/fsck.ext3> |
| Malzilla | Malware hunting tool. | <http://malzilla.sourceforge.net/> |
| NetworkMiner | Network Forensic Analysis Tool. | <http://www.netresec.com/?page=NetworkMiner> |
| PDF Streams Inflater | Find and extract zlib files compressed in PDF files. | <http://malzilla.sourceforge.net/downloads.html> |
| Pngcheck | Verifies the integrity of PNG and dump all of the chunk-level information in human-readable form. | <http://www.libpng.org/pub/png/apps/pngcheck.html> |
| ResourcesExtract | Extract various filetypes from exes. | <http://www.nirsoft.net/utils/resources_extract.html> |
| Shellbags | Investigate NT\_USER.dat files. | <https://github.com/williballenthin/shellbags> |
| Snow | A Whitespace Steganography Tool. | <https://sbmlabs.com/notes/snow_whitespace_steganography_tool> |
| USBRip | Simple CLI forensics tool for tracking USB device artifacts (history of USB events) on GNU/Linux. | <https://github.com/snovvcrash/usbrip> |
| Volatility | To investigate memory dumps. | <https://github.com/volatilityfoundation/volatility> |
| Wireshark | Used to analyze pcap or pcapng files | <https://www.wireshark.org> |
| OfflineRegistryView | Simple tool for Windows that allows you to read offline Registry files from external drive and view the desired Registry key in .reg file format. | <https://www.nirsoft.net/utils/offline_registry_view.html> |
| Registry Viewer® | Used to view Windows registries. | <https://accessdata.com/product-download/registry-viewer-2-0-0> |
