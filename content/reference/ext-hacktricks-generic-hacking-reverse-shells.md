## Auto-generated shell tools

Several web and command-line helpers can generate bind- and reverse-shell payloads for different interpreters and operating systems:

- **reverse-shell.sh** and **revshells.com** provide browser-based payload generators.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen**, and **rsg** generate payloads from the command line or a local interface.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** is a small cross-platform reverse shell for Linux and Windows.<sup>[[7]](#references)</sup>
- **pyminifier** is not a shell generator, but can minify or obfuscate Python payloads when that transformation is useful.<sup>[[6]](#references)</sup>
