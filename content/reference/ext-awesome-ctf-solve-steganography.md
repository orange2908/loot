Curated CTF tools for **steganography** (solve).

> Tools used for solving Steganography challenges

| Tool | What it does | Link |
|---|---|---|
| AperiSolve | Aperi'Solve is a platform which performs layer analysis on image (open-source). | <https://aperisolve.fr/> |
| Convert | Convert images b/w formats and apply filters. | <http://www.imagemagick.org/script/convert.php> |
| Exif | Shows EXIF information in JPEG files. | <http://manpages.ubuntu.com/manpages/trusty/man1/exif.1.html> |
| Exiftool | Read and write meta information in files. | <https://linux.die.net/man/1/exiftool> |
| Exiv2 | Image metadata manipulation tool. | <http://www.exiv2.org/manpage.html> |
| Image Steganography | Embeds text and files in images with optional encryption. Easy-to-use UI. | <https://sourceforge.net/projects/image-steg/> |
| Image Steganography Online | This is a client-side Javascript tool to steganographically hide images inside the lower "bits" of other images | <https://incoherency.co.uk/image-steganography> |
| ImageMagick | Tool for manipulating images. | <http://www.imagemagick.org/script/index.php> |
| Outguess | Universal steganographic tool. | <https://www.freebsd.org/cgi/man.cgi?query=outguess+&apropos=0&sektion=0&manpath=FreeBSD+Ports+5.1-RELEASE&format=html> |
| Pngtools | For various analysis related to PNGs. | <https://packages.debian.org/sid/pngtools> |
| SmartDeblur | Used to deblur and fix defocused images. | <https://github.com/Y-Vladimir/SmartDeblur> |
| Steganabara | Tool for stegano analysis written in Java. | <https://www.openhub.net/p/steganabara> |
| SteganographyOnline | Online steganography encoder and decoder. | <https://stylesuxx.github.io/steganography/> |
| Stegbreak | Launches brute-force dictionary attacks on JPG image. | <https://linux.die.net/man/1/stegbreak> |
| StegCracker | Steganography brute-force utility to uncover hidden data inside files. | <https://github.com/Paradoxis/StegCracker> |
| stegextract | Detect hidden files and text in images. | <https://github.com/evyatarmeged/stegextract> |
| Steghide | Hide data in various kind of images. | <http://steghide.sourceforge.net/> |
| StegOnline | Conduct a wide range of image steganography operations, such as concealing/revealing files hidden within bits (open-source). | <https://georgeom.net/StegOnline/upload> |
| Stegsolve | Apply various steganography techniques to images. | <http://www.caesum.com/handbook/Stegsolve.jar> |
| Zsteg | PNG/BMP analysis. | <https://github.com/zed-0xff/zsteg/> |
