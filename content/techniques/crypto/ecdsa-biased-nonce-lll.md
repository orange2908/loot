## TL;DR

`s = k^{-1}(h + r d)` rearranges to `k = s^{-1} h + s^{-1} r d mod n`. If each `k` is *small*
(or has known bits), then `t_i d - u_i mod n` is small for known `t_i, u_i` -- that is the
Hidden Number Problem. Put the `t_i` in a lattice, reduce, and `d` appears. Roughly
`log2(n)/bias + 2` signatures suffice; 3 bits of bias and 60-100 signatures is a classic
real-world break.

## Recognise it

- `k = random.getrandbits(160)` while `n` is 256 bits.
- `k = int(time.time()) * something` -- small range.
- `k = (fixed_prefix << 128) | random.getrandbits(128)`.
- The challenge gives you hundreds of signatures and no repeated `r`.
- The word "bias", "leak", "MSB", "Minerva", "LadderLeak", or "timing" in the prompt.

## Theory

**Reduction to HNP.** From `s k = h + r d (mod n)`:

$$k_i \equiv s_i^{-1} h_i + s_i^{-1} r_i \, d \pmod n$$

Set `t_i = s_i^{-1} r_i mod n` and `u_i = -s_i^{-1} h_i mod n`. Then

$$k_i \equiv t_i d - u_i \pmod n, \qquad 0 \le k_i < K$$

with `K = 2^{log2(n) - B}` when the top `B` bits of every nonce are zero. Finding `d` given
that `t_i d - u_i` is small for many `i` is exactly Boneh-Venkatesan's Hidden Number Problem.

**The lattice.** Work with the `(m+2)`-dimensional integer lattice generated by the rows

$$\begin{pmatrix}
n^2 & & & & \\
& \ddots & & & \\
& & n^2 & & \\
n t_1 & \cdots & n t_m & K & 0 \\
n u_1 & \cdots & n u_m & 0 & nK
\end{pmatrix}$$

The combination `d * (row_{m+1}) - (row_{m+2}) - sum c_i (row_i)`, with `c_i` chosen to reduce
each coordinate mod `n`, equals

$$\big(n k_1, \; \ldots, \; n k_m, \; dK, \; -nK\big)$$

whose norm is about `nK sqrt(m+1)`, while the lattice determinant is `n^{2m} \cdot K \cdot nK`,
so the Gaussian heuristic predicts a shortest vector of length about
`sqrt(dim) * det^{1/dim}`. The target beats that as soon as

$$m \cdot B > \log_2 n + \text{(a couple of bits)}$$

i.e. **total leaked bits must exceed the key size**, plus margin. Read `d = v[m] / K mod n`
from any reduced row whose `m`-th coordinate is nonzero.

**Recentring (worth 1 free bit).** If `0 <= k_i < K`, then `k_i - K/2` lies in `(-K/2, K/2)`.
Substituting `u_i' = u_i + K/2` halves the target norm, which is exactly one extra bit of
bias for free. Always do it.

**LSB bias.** If the low `B` bits of `k` are known to be `z_i` (say `k = 2^B k' + z_i`), then
`k' = (k - z_i)/2^B` is small; substitute `t_i' = t_i * 2^{-B}`, `u_i' = (u_i + z_i) * 2^{-B}`
and you are back to the MSB case.

**Known middle bits / arbitrary affine leak.** Any `k_i = a_i x_i + b_i` with `a_i, b_i` known
and `x_i` small folds into the same shape by scaling `t_i` and `u_i`.

**When LLL is not enough.** With only `log2(n)/B + 1` signatures the target is barely shorter
than the Gaussian heuristic. Fixes in order of cost: add signatures, recentre, switch to
`BKZ(block_size=20..40)`, randomise the subset of signatures used and retry, or use
`flatter` for large dimension.

## Attack

1. Collect `m` signatures and their hashes; determine the bias `B`.
2. Compute `t_i = s_i^{-1} r_i`, `u_i = -s_i^{-1} h_i`, recentre by `K/2`.
3. Build the basis, reduce with LLL (or BKZ).
4. For every reduced row, read `d = v[m] * K^{-1} mod n`, both signs.
5. Verify `d G == Q`, or verify that all `(t_i d - u_i) mod n` are small.
6. If nothing works, add signatures or increase the block size.

## Code

```python
#!/usr/bin/env python3
"""Biased-nonce ECDSA -> HNP -> LLL, with a self-contained exact LLL."""
import hashlib
import random
from fractions import Fraction

# ---- secp256k1 ----------------------------------------------------------

P = 2**256 - 2**32 - 977
N = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141
G = (0x79BE667EF9DCBBAC55A06295CE870B07029BFCDB2DCE28D959F2815B16F81798,
     0x483ADA7726A3C4655DA4FBFC0E1108A8FD17B448A68554199C47D08FFB10D4B8)

def ec_add(A, B):
    if A is None:
        return B
    if B is None:
        return A
    (x1, y1), (x2, y2) = A, B
    if x1 == x2 and (y1 + y2) % P == 0:
        return None
    lam = ((3 * x1 * x1) * pow(2 * y1 % P, -1, P) if A == B
           else (y2 - y1) * pow((x2 - x1) % P, -1, P)) % P
    x3 = (lam * lam - x1 - x2) % P
    return (x3, (lam * (x1 - x3) - y1) % P)

def ec_mul(k, A):
    R, S, k = None, A, k % N
    while k:
        if k & 1:
            R = ec_add(R, S)
        S, k = ec_add(S, S), k >> 1
    return R

def h_of(msg):
    return int.from_bytes(hashlib.sha256(msg).digest(), "big") % N

def sign(d, msg, k):
    r = ec_mul(k, G)[0] % N
    return r, pow(k, -1, N) * (h_of(msg) + r * d) % N

# ---- exact LLL (Cohen 2.6.3) -------------------------------------------

def _dot(u, v):
    return sum(a * b for a, b in zip(u, v))

def _rnd(x):
    return int(x + Fraction(1, 2)) if x >= 0 else -int(-x + Fraction(1, 2))

def lll(basis, delta=Fraction(99, 100)):
    b = [[int(x) for x in row] for row in basis]
    n = len(b)
    if n < 2:
        return b
    mu = [[Fraction(0)] * n for _ in range(n)]
    bs, B = [None] * n, [Fraction(0)] * n
    bs[0] = [Fraction(x) for x in b[0]]
    B[0] = _dot(bs[0], bs[0])
    kmax, k = 0, 1

    def red(i, j):
        if abs(mu[i][j]) <= Fraction(1, 2):
            return
        q = _rnd(mu[i][j])
        b[i] = [x - q * y for x, y in zip(b[i], b[j])]
        mu[i][j] -= q
        for t in range(j):
            mu[i][t] -= q * mu[j][t]

    while k < n:
        if k > kmax:
            kmax = k
            row = [Fraction(x) for x in b[k]]
            v = list(row)
            for j in range(k):
                mu[k][j] = Fraction(0) if B[j] == 0 else _dot(row, bs[j]) / B[j]
                v = [a - mu[k][j] * c for a, c in zip(v, bs[j])]
            bs[k], B[k] = v, _dot(v, v)
        red(k, k - 1)
        if B[k] < (delta - mu[k][k - 1] ** 2) * B[k - 1]:
            m_ = mu[k][k - 1]
            BB = B[k] + m_ * m_ * B[k - 1]
            b[k], b[k - 1] = b[k - 1], b[k]
            mu[k][k - 1] = m_ * B[k - 1] / BB
            old = bs[k - 1]
            bs[k - 1] = [x + m_ * y for x, y in zip(bs[k], old)]
            bs[k] = [-mu[k][k - 1] * x + (B[k] / BB) * y for x, y in zip(bs[k], old)]
            B[k], B[k - 1] = B[k - 1] * B[k] / BB, BB
            for j in range(k - 1):
                mu[k][j], mu[k - 1][j] = mu[k - 1][j], mu[k][j]
            for i in range(k + 1, kmax + 1):
                t = mu[i][k]
                mu[i][k] = mu[i][k - 1] - m_ * t
                mu[i][k - 1] = t + mu[k][k - 1] * mu[i][k]
            k = max(1, k - 1)
        else:
            for j in range(k - 2, -1, -1):
                red(k, j)
            k += 1
    return b

# ---- the HNP solver -----------------------------------------------------

def hnp(ts, us, n, bound, recentre=True):
    """Find alpha with 0 <= (alpha*t_i - u_i) mod n < bound."""
    m = len(ts)
    if recentre:                       # shift the window to (-bound/2, bound/2): one free bit
        us = [(u + bound // 2) % n for u in us]
        bound = bound // 2 + 1
    dim = m + 2
    M = [[0] * dim for _ in range(dim)]
    for i in range(m):
        M[i][i] = n * n
        M[m][i] = n * ts[i] % (n * n)
        M[m + 1][i] = n * us[i] % (n * n)
    M[m][m] = bound
    M[m + 1][m + 1] = n * bound
    inv = pow(bound, -1, n)
    for row in lll(M):
        if row[m] == 0:
            continue
        for cand in ((row[m] * inv) % n, (-row[m] * inv) % n):
            yield cand

def recover_key(sigs, hashes, n, bias_bits, pub=None):
    """sigs = [(r, s)], nonces have their top bias_bits bits zero."""
    K = 1 << (n.bit_length() - bias_bits)
    ts, us = [], []
    for (r, s), h in zip(sigs, hashes):
        si = pow(s, -1, n)
        ts.append(si * r % n)
        us.append(-si * h % n)
    for cand in hnp(ts, us, n, K):
        if cand == 0:
            continue
        if pub is not None:
            if ec_mul(cand, G) == pub:
                return cand
        elif all((cand * t - u) % n < K for t, u in zip(ts, us)):
            return cand
    return None

if __name__ == "__main__":
    rng = random.Random(2024)
    d = rng.randrange(1, N)
    Q = ec_mul(d, G)

    # 8 signatures, each nonce only 192 bits (top 64 bits are zero) -> 512 leaked bits
    BIAS, M = 64, 8
    K = 1 << (N.bit_length() - BIAS)
    sigs, hashes, nonces = [], [], []
    for i in range(M):
        msg = f"message number {i}".encode()
        k = rng.randrange(1, K)
        sigs.append(sign(d, msg, k))
        hashes.append(h_of(msg))
        nonces.append(k)
    assert len({r for r, _ in sigs}) == M, "no nonce reuse here, r values all differ"
    print(f"[ok] {M} signatures, each k < 2^{K.bit_length() - 1} ({BIAS} bits of bias)")
    print(f"    total leaked bits {M * BIAS} > key size {N.bit_length()}: enough for LLL")

    rec = recover_key(sigs, hashes, N, BIAS, pub=Q)
    assert rec == d, "HNP failed"
    print(f"[ok] private key recovered: d = {hex(rec)}")

    # without the public key, verification is 'are all residues small?'
    rec2 = recover_key(sigs, hashes, N, BIAS)
    assert rec2 == d
    print("[ok] same result with no public key, using the smallness check only")

    # sanity: the recovered key reproduces every nonce
    for (r, s), h, k in zip(sigs, hashes, nonces):
        assert pow(s, -1, N) * (h + r * rec) % N == k
    print("[ok] all nonces reconstructed from the recovered key")
    print("all self-tests passed")
```

## Variants and pitfalls

- **Too few signatures.** The single most common failure. Compute
  `m > log2(n) / B` and add 30-50% margin. With `B = 1` you need hundreds and BKZ.
- **Forgetting to recentre.** Costs you one bit of bias, which is the difference between
  "works" and "never works" at the margin.
- **Wrong hash truncation.** `h` must match exactly what the signer used: same hash function,
  same truncation to `n.bit_length()` bits, same endianness.
- **`u_i` sign.** `u_i = -s^{-1} h` (not `+`). A sign error gives a lattice with no short
  vector, which looks identical to "not enough signatures".
- **Reading `d` from the wrong coordinate.** Scan *all* reduced rows and both signs. The
  target vector is usually, but not always, the first row.
- **Non-uniform bias.** If only *some* nonces are short, include only those; one bad sample
  destroys the lattice. When you do not know which, sample random subsets and retry.
- **Bias in the middle.** `k = prefix || random || suffix` still reduces to HNP; scale by
  `2^{-suffix_bits}` and subtract the known prefix contribution.
- **EdDSA is immune** (deterministic nonce from the key and the message) unless the
  implementation adds its own randomness badly.
- **Dimension explodes.** Above dimension ~60 the exact Python LLL crawls. Use `fpylll`,
  Sage's `.BKZ()`, or `flatter`.

n = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141

M[m, m] = K
M[m + 1, m + 1] = n * K
