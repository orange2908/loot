## TL;DR

An LCG state is $x_i \equiv A_i x_0 + B_i \pmod m$ where $A_i = a^i$ and
$B_i = c\,(a^{i-1} + \cdots + 1)$ - both computable from the public parameters. If you
only see $y_i = \lfloor x_i / 2^k \rfloor$, then
$z_i = x_i - y_i 2^k \in [0, 2^k)$ is *small*. Collecting the congruences
$A_i x_0 + B_i - y_i 2^k \equiv z_i \pmod m$ turns the problem into a **closest vector
problem**: build the lattice generated by $(A_0, \ldots, A_{t-1})$ and $m e_i$, run
LLL, then Babai's nearest-plane against the target $(y_i 2^k - B_i)$. The coefficient
of the first row is $x_0$.

Rule of thumb: you need roughly $t > \log_2 m / (\log_2 m - k)$ outputs. Losing 16 of
48 bits needs ~2, but take 8-12 for safety margin.

## Recognise it

- Outputs are visibly narrower than the state: 32-bit values from a 48-bit generator,
  15-bit values from a 32-bit one.
- `prng-lcg-recovery`'s gcd trick returns a modulus that does not reproduce the data.
- Decompiled code with `(seed >> 16)`, `>>> 16`, `(s >> 16) & 0x7FFF`.
- Java `Random.nextInt()` (48-bit state, 32-bit output), MSVC `rand()`
  (32-bit state, 15-bit output), `drand48` families.

## Theory

**Setup.** $x_{i+1} = a x_i + c \bmod m$. Unroll:
$$x_i \equiv a^i x_0 + c\frac{a^i - 1}{a - 1} \pmod m$$
(compute $B_i$ iteratively as $B_i = a B_{i-1} + c$, which avoids needing
$(a-1)^{-1}$).

**Truncation.** Observed $y_i$, unknown $z_i = x_i \bmod 2^k$, with
$x_i = y_i 2^k + z_i$ and $0 \le z_i < 2^k$.

Substituting:
$$z_i \equiv A_i x_0 - (y_i 2^k - B_i) \pmod m$$

**The lattice.** Consider the lattice $L \subset \mathbb{Z}^t$ generated by the rows
$$v_0 = (A_0, A_1, \ldots, A_{t-1}), \quad v_i = m\,e_i \ (i = 1 \ldots t-1)$$
(Since $A_0 = 1$, $v_0$ covers the first coordinate and the basis has determinant
$m^{t-1}$.) Every choice of $x_0$ and of the reduction multiples $k_i$ gives a lattice
point $x_0 v_0 + \sum k_i v_i$ whose $i$-th coordinate is $A_i x_0 - k_i m$.

Set the target $\mathbf{t} = (y_0 2^k - B_0, \ldots, y_{t-1}2^k - B_{t-1})$. The true
$x_0$ produces a lattice point at distance $\|\mathbf{z}\| \le 2^k \sqrt{t}$ from the
target - far shorter than the lattice's typical covering radius when
$2^{kt} \ll m^{t-1}$, i.e. when $t(\log_2 m - k) > \log_2 m$. So the closest vector
**is** the answer.

**Solving CVP.** LLL-reduce the basis, then run Babai's nearest-plane algorithm. The
Babai coefficient of the reduced row that corresponds to $v_0$ is not directly $x_0$,
but the recovered lattice point's first coordinate is $x_0 \bmod m$ - read it off there.
The residual `target - closest` is $-z_i$.

**If $a, c, m$ are unknown**, first try the published parameter tables (Java, MSVC,
glibc TYPE_0, MMIX, Borland). Recovering unknown parameters *and* truncation at once is
much harder; the practical route is to guess $m$ (a power of two) and solve for $a$ with
a second lattice or with z3 on a few candidate values.

## Attack

1. Identify $a$, $c$, $m$ and the truncation $k$. (`y = state >> k`.)
2. Collect $t$ consecutive outputs with $t(\log_2 m - k) > \log_2 m$, plus margin.
3. Build $A_i = a^i \bmod m$ and $B_i$ iteratively.
4. Build the basis, LLL-reduce it, Babai against the target.
5. Read $x_0$ off the first coordinate; verify by regenerating all $y_i$.
6. Roll forward (or backward with $a^{-1}$) to predict.
7. If it fails: add more outputs, check the truncation direction (high bits vs low
   bits), and confirm the outputs are truly consecutive.

## Code

```python
#!/usr/bin/env python3
"""Truncated LCG state recovery via LLL + Babai, with a self-contained exact-rational
LLL so there is no fpylll/Sage dependency. Self-testing.

For production-size lattices use fpylll or Sage - this LLL is O(n^4)-ish with Fraction
arithmetic and is meant for the t <= 20 lattices that CTF truncated-LCG problems need.
"""
from __future__ import annotations

import random
from fractions import Fraction


# ----------------------------- lattice tools -------------------------------
def _gso(B):
    """Gram-Schmidt over the rationals. Returns (B*, mu)."""
    n, m = len(B), len(B[0])
    bs, mu = [], [[Fraction(0)] * n for _ in range(n)]
    for i in range(n):
        v = [Fraction(x) for x in B[i]]
        for j in range(i):
            d = sum(x * x for x in bs[j])
            mu[i][j] = (sum(Fraction(B[i][t]) * bs[j][t] for t in range(m)) / d
                        if d else Fraction(0))
            v = [v[t] - mu[i][j] * bs[j][t] for t in range(m)]
        mu[i][i] = Fraction(1)
        bs.append(v)
    return bs, mu


def _round_frac(x: Fraction) -> int:
    return int(x + Fraction(1, 2)) if x > 0 else -int(-x + Fraction(1, 2))


def lll(B, delta: Fraction = Fraction(99, 100)):
    """Textbook LLL. Recomputes the GSO only after a swap, which keeps it usable."""
    B = [list(map(int, row)) for row in B]
    n, m = len(B), len(B[0])
    bs, mu = _gso(B)
    norms = [sum(x * x for x in v) for v in bs]
    k = 1
    while k < n:
        for j in range(k - 1, -1, -1):
            if abs(mu[k][j]) > Fraction(1, 2):
                q = _round_frac(mu[k][j])
                B[k] = [B[k][t] - q * B[j][t] for t in range(m)]
                for t in range(j + 1):
                    mu[k][t] -= q * mu[j][t]
        if norms[k] >= (delta - mu[k][k - 1] ** 2) * norms[k - 1]:
            k += 1
        else:
            B[k], B[k - 1] = B[k - 1], B[k]
            bs, mu = _gso(B)
            norms = [sum(x * x for x in v) for v in bs]
            k = max(k - 1, 1)
    return B


def babai_nearest_plane(B, target):
    """Closest lattice vector to `target`. Returns (vector, coefficients)."""
    bs, _ = _gso(B)
    n, m = len(B), len(target)
    b = [Fraction(x) for x in target]
    coeffs = [0] * n
    for i in range(n - 1, -1, -1):
        d = sum(x * x for x in bs[i])
        if d == 0:
            continue
        c = sum(b[j] * bs[i][j] for j in range(m)) / d
        ci = _round_frac(c)
        coeffs[i] = ci
        b = [b[j] - ci * Fraction(B[i][j]) for j in range(m)]
    v = [sum(coeffs[i] * B[i][j] for i in range(n)) for j in range(m)]
    return v, coeffs


# --------------------------- the actual attack -----------------------------
class LCG:
    def __init__(self, seed: int, a: int, c: int, m: int):
        self.a, self.c, self.m, self.state = a, c, m, seed % m

    def next_state(self) -> int:
        self.state = (self.a * self.state + self.c) % self.m
        return self.state

    def truncated(self, k: int) -> int:
        """Emit only the high bits: state >> k."""
        return self.next_state() >> k


def unroll_coeffs(a: int, c: int, m: int, t: int):
    """A[i], B[i] with x_i = A[i]*x_0 + B[i] (mod m)."""
    A = [pow(a, i, m) for i in range(t)]
    B = [0] * t
    for i in range(1, t):
        B[i] = (a * B[i - 1] + c) % m
    return A, B


def min_outputs_needed(m: int, k: int) -> int:
    """t must satisfy t*(log2 m - k) > log2 m."""
    bits = m.bit_length()
    lost = bits - k
    if lost <= 0:
        raise ValueError("nothing is published")
    return bits // lost + 2


def recover_truncated_lcg(ys, a: int, c: int, m: int, k: int):
    """High bits only -> the full first state x_0 (and the low bits z_i)."""
    t = len(ys)
    A, B = unroll_coeffs(a, c, m, t)
    basis = [A[:]] + [[m if j == i else 0 for j in range(t)] for i in range(1, t)]
    reduced = lll(basis)
    target = [(ys[i] * (1 << k) - B[i]) % m for i in range(t)]
    closest, _ = babai_nearest_plane(reduced, target)
    x0 = closest[0] % m
    z = [(target[i] - closest[i]) for i in range(t)]
    return x0, z


def verify(x0: int, ys, a: int, c: int, m: int, k: int) -> bool:
    s = x0
    for y in ys:
        if s >> k != y:
            return False
        s = (a * s + c) % m
    return True


def predict_truncated(x0: int, a: int, c: int, m: int, k: int, count: int):
    """Future truncated outputs, starting from the state AFTER the observed ones."""
    out, s = [], x0
    for _ in range(count):
        s = (a * s + c) % m
        out.append(s >> k)
    return out


if __name__ == "__main__":
    rng = random.Random(0xA11CE)

    # --- 1. Java-style: 48-bit state, top 32 bits published ---------------
    a, c, m, k = 0x5DEECE66D, 0xB, 1 << 48, 16
    t = 8
    assert min_outputs_needed(m, k) <= t
    seed = rng.getrandbits(48)
    gen = LCG(seed, a, c, m)
    states = []
    s = seed
    for _ in range(t):
        states.append(s)
        s = (a * s + c) % m
    ys = [x >> k for x in states]

    x0, z = recover_truncated_lcg(ys, a, c, m, k)
    assert x0 == states[0], (x0, states[0])
    assert all(-(1 << k) < v <= 0 for v in z), z[:3]
    assert verify(x0, ys, a, c, m, k)
    print(f"[ok] 48-bit LCG, 16 bits truncated: recovered x0 = {x0:#014x} "
          f"from {t} outputs")

    # the residual is exactly minus the hidden low bits
    assert [-v for v in z] == [x & ((1 << k) - 1) for x in states]
    print("[ok] the Babai residual is exactly the hidden low bits")

    # --- 2. prediction ------------------------------------------------------
    real = []
    s = states[-1]
    for _ in range(5):
        s = (a * s + c) % m
        real.append(s >> k)
    pred = predict_truncated(states[-1], a, c, m, k, 5)
    assert pred == real
    print(f"[ok] predicted the next 5 truncated outputs: {pred[:2]}...")

    # --- 3. 32-bit LCG losing 20 bits (only 12 bits published) ------------
    a2, c2, m2, k2 = 1103515245, 12345, 1 << 32, 20
    t2 = 10
    assert min_outputs_needed(m2, k2) <= t2
    seed2 = rng.getrandbits(32)
    states2 = []
    s = seed2
    for _ in range(t2):
        states2.append(s)
        s = (a2 * s + c2) % m2
    ys2 = [x >> k2 for x in states2]
    x02, _ = recover_truncated_lcg(ys2, a2, c2, m2, k2)
    assert x02 == states2[0], (x02, states2[0])
    print(f"[ok] 32-bit LCG with only 12 bits published: recovered "
          f"x0 = {x02:#010x} from {t2} outputs")

    # --- 4. too few outputs must fail (that is the point of the bound) ----
    few = ys2[:2]
    bad, _ = recover_truncated_lcg(few, a2, c2, m2, k2)
    assert bad != states2[0], "2 outputs should NOT be enough here"
    print(f"[ok] with only 2 outputs the lattice is underdetermined, as predicted "
          f"(need >= {min_outputs_needed(m2, k2)})")

    # --- 5. the lattice tools themselves -----------------------------------
    B = [[1, 1, 1], [-1, 0, 2], [3, 5, 6]]
    R = lll(B)
    assert all(sum(x * x for x in R[i]) <= sum(x * x for x in R[i + 1]) * 4
               for i in range(len(R) - 1))
    v, _ = babai_nearest_plane(R, [10, 10, 10])
    assert isinstance(v, list) and len(v) == 3
    print(f"[ok] LLL reduced a toy basis to {R}")
    print("all self-tests passed")
```

## Variants & pitfalls

- **Too few outputs.** The bound $t(\log_2 m - k) > \log_2 m$ is not optional. If you
  are one short, the closest vector is not the right one and you get a plausible-
  looking but wrong $x_0$. **Always verify** by regenerating the observed outputs.
- **Babai is only approximate.** If nearest-plane fails, use the *embedding* technique
  (append the target as an extra basis row with a weight and reduce again), or enumerate
  a few nearby coefficient vectors.
- **Low bits published instead of high bits.** If the output is `state & mask`, the
  unknown is the *high* part, which is not small - the lattice must be rebuilt with the
  roles swapped (and low bits of a power-of-two LCG are famously weak anyway: bit $j$
  has period $2^{j+1}$, so just solve bit by bit).
- **Non-consecutive outputs.** If the service skips values, use $a^{s}$ for the actual
  step size $s$; the structure is unchanged.
- **Unknown multiplier.** Guess from the standard tables first. If it is genuinely
  unknown, you need a bilinear/Coppersmith-style approach, not this lattice.
- **Modulus not a power of two.** The maths is identical; only $2^k$ becomes whatever
  scaling the truncation applies.
- **Precision.** Fraction-based LLL is exact but slow. For $t > 20$ use `fpylll`
  (`from fpylll import IntegerMatrix, LLL`) or Sage (`Matrix(ZZ, B).LLL()`), which are
  orders of magnitude faster.
- **Java specifically.** `nextInt()` returns `(int)(seed >>> 16)` from a 48-bit state,
  so $k = 16$ - but `nextInt(bound)` does rejection sampling and `nextLong()` uses two
  draws. See `prng-java-random`; for Java, brute-forcing the 48-bit seed from *two*
  consecutive `nextInt()` values by iterating the 16 unknown low bits is usually faster
  than a lattice.
- **Do not confuse this with glibc `random()`**, which is not an LCG at all.

## Tools

- **fpylll** - <https://github.com/fplll/fpylll> - fast LLL/BKZ from Python.
- **SageMath** - `Matrix(ZZ, rows).LLL()`, `IntegerLattice(...).closest_vector(t)`.
- **`olll` / `lll` PyPI packages** - small pure-Python LLLs if you want a dependency
  rather than the code above.
- **z3** - viable when $t$ is small and the truncation is awkward, but it scales badly
  past ~10 unknowns of 32 bits.
